# Typography

Typography tokens for the Portfolio design system.

## Font Families

- Persian: Vazirmatn
- English: Inter

## Font Weights

- Regular: 400
- Medium: 500
- Semibold: 600
- Bold: 700

## Type Scale

The typography scale is shared across Angular, React, and Next.js.

The values are intentionally framework-independent and can be consumed by each application through the shared design system.
